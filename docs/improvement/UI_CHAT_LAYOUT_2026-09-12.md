# 채팅 레이아웃 개선

## 요구사항과 설계
- 채팅 입력은 화면 하단에 고정한다. Streamlit 1.32.2의 기본 동작을 활용하기 위해 탭 컨테이너를 최상위 화면 선택으로 바꾼다.
- 문서 관리 화면에서는 입력창을 표시하지 않는다.
- 본문 폭을 제한하고 질문과 답변의 시각적 위계를 구분한다.
- 요약 제목은 한 번만 표시하고 상세 설명은 본문에 바로 표시한다. 참고 자료만 접는다.
- 빈 대화에서는 시작 안내를 표시하고 대화 관리 버튼·피드백은 숨긴다.
- 기존 수정 사항과 원문 답변은 보존한다. API·DB 구조 변경은 없다.

## 작업 및 검증
- [x] 화면 선택, 하단 입력, 대화 관리와 빈 상태 정리
- [x] 답변 렌더링과 반응형 스타일 개선
- [x] 중복 요약·별표 목록·붙은 표 행 회귀 테스트, 오프라인 202건 통과
- [x] ruff format 검사(변경 Python 파일), ruff check 전체, git diff --check 통과
- [x] 브라우저에서 하단 위치·화면 전환 확인: 1760×883 화면에서 입력 y=783, 높이 44px. 문서 관리에서 입력 0개.
- [x] UI 명세와 변경 이력 갱신

## 검증 한계
- Aside REPL은 setViewportSize를 지원하지 않아 모바일 실화면 검증은 미완료. 반응형 CSS는 적용.
- 기존 테스트·의존성 경고 55건이 남아 있음. 이번 UI 변경과 무관하여 수정하지 않음.
- 기존 대화로 렌더링을 확인했으며 새 외부 LLM 질의는 실행하지 않음.
- Makefile의 전체 자동 포맷 대신 변경 파일만 포맷 검사하고, 실패를 숨길 수 있는 make 래퍼 대신 ruff/pytest 직접 실행으로 종료 코드 확인.
