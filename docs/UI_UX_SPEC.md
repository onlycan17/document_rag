# UI/UX 명세서

본 문서는 Streamlit UI(app.py)와 run_rag.py 메뉴 UX를 기준으로 사용 흐름을 설명합니다.

## 1. 사용자 여정
- 시작: `python run_rag.py` 실행 → 메뉴에서 1(앱 실행), 2(벡터DB), 3(테스트), 4(설정), 5(프로젝트 정보).
- 앱 실행 후: 좌측 사이드바에서 모델/스트리밍/검색 파라미터 설정 → 질문 입력 → 실시간 답변.

## 2. 핵심 화면 요소
- 메인 입력창: 채팅 화면 하단에 고정. 최상위 화면 선택에서 문서 관리로 전환하면 숨김.
- 빈 대화: 시작 안내와 질문 예시 표시. 대화가 있을 때만 새 대화·대화 저장·피드백 표시.
- 답변 영역:
  - 스트리밍 활성 시 타자 효과로 실시간 표시(용어(설명: 토큰이 생성되는 대로 순차 출력)).
  - 기본 구조: `핵심 요약 → 상세 설명 → 참고 자료` 순서를 유지하되 렌더링은 섹션 단위로 분리(`src/utils/answer_render.py`).
    - `핵심 요약`: 작은 제목 한 번만 표시. 반복 섹션의 본문은 보존.
    - `상세 설명`: 답변 본문에 바로 표시.
    - `참고 자료`: 접기/펼치기(기본 접힘) 카드.
  - 인라인 `[출처 N]`는 `출처 N` 뱃지(`.cite`)로 표시하고, 헤딩이 앞 텍스트에 붙어 나와도 줄 단위로 정규화해 원문 `###`가 노출되지 않게 한다.
  - 채팅 답변 타이포(헤딩 스케일·행간·메시지 간격)는 `ui/styles.py`의 CSS로 조정.
  - 출처/관련 문서 메타데이터 표시(파일명, 청크 정보 등).
- 사이드바 옵션(예시):
  - 모델/프로바이더 선택(Upstage/OpenAI/Google/Anthropic/Local)
  - 검색 k, 하이브리드/MMR 토글, 임계값 설정
  - 스트리밍 on/off 토글

## 3. 사용성 원칙
- 쉬운 한국어: 전문 용어는 괄호로 풀이.
- 진행 상황 가시화: “검색 중/생성 중” 상태 메시지.
- 오류 친화성: 키 미설정/DB 미존재 시 실행 경로 안내.

## 4. 접근성/반응성
- 키보드 중심 입력 흐름, 단일 열 레이아웃, 명확한 대비.
- 본문 최대 폭 960px, 좁은 화면에서 여백 축소. 참고 자료는 접기·펼치기로 표시.

## 5. 빈틈/개선 포인트
- 응답 메타 일관성(`참조 문서 0개`/`모델 Unknown` 등 실제 값 반영) — 후속.
- 출처 하이라이트(문단 단위 점프/미리보기).
- 답변 내 용어 툴팁(초등학생도 이해 가능한 수준의 안내).
- 다크 모드(시각 피로 개선).
