# ERD 문서

본 프로젝트는 주 데이터 저장소로 벡터 데이터베이스와 로컬 파일 시스템을 사용합니다. 전통적인 관계형 테이블은 없지만, 이해를 돕기 위해 개념적 ERD를 텍스트로 표현합니다.

## 1. 개체(Entity)
- **Document**: 업로드된 문서, 메타데이터(파일명, 페이지 번호, 이미지 경로 등)를 포함.
- **Chunk**: 문서를 분리한 텍스트 조각. 벡터 데이터베이스에 저장.
- **Embedding**(설명: 텍스트를 숫자 벡터로 바꾼 결과): Chunk마다 하나씩 연결.
- **ChatSession**: 사용자의 질문과 답변 기록.

## 2. 관계(Relationship)
- Document 1 --- N Chunk
- Chunk 1 --- 1 Embedding
- ChatSession 1 --- N Document (답변에 사용된 문서 목록)

## 3. 이번 리팩토링 영향
- 데이터 구조 변경 없음.
- 이미지 메타데이터를 읽어오는 위치만 통일.

## 4. 용어 정리
- 엔티티(설명: 데이터베이스에서 관리하는 대상을 의미)
- 관계(설명: 엔티티 사이에 어떤 연결이 있는지를 표현)
