# UI/UX 명세서

## 1. 사용자 흐름
1. 사용자는 사이드바에서 모델과 전처리 옵션을 선택합니다.
2. 메인 영역에서 질문을 입력하면 스트리밍 형태로 답변이 표시됩니다.
3. 답변 아래에 관련 이미지와 참고 문서 정보가 나타납니다.
4. 필요할 경우 채팅 기록을 다운로드하거나 피드백을 남길 수 있습니다.

## 2. 이번 리팩토링에서 눈에 띄는 변화
- 겉모습은 동일합니다. 다만 이미지가 나타나는 순서를 정렬하고, 경로 해석 실패 시 오류 메시지를 간결하게 보여줍니다.
- 스트리밍 진행 상황 메시지를 상태 창 하나로 통일해 화면이 덜 번쩍이도록 합니다.

## 3. 상호작용 규칙
- 스트리밍 중 오류가 발생하면 `status_placeholder`에 한 번만 경고를 띄웁니다.
- 이미지 로딩 실패 시 `st.warning`으로 간단히 안내하고, 상세 로그는 `logger`에 남깁니다.

## 4. 접근성 고려
- 이미지 캡션에 파일명과 출처를 명시해 스크린 리더가 내용을 전달할 수 있도록 합니다.
- 중요 상태 메시지는 아이콘 대신 텍스트로도 뜻을 알 수 있게 합니다.

## 5. 용어 정리
- 스트리밍(설명: 처리 결과를 한 번에 주지 않고, 진행하면서 조금씩 보여주는 방식)
- 플레이스홀더(설명: Streamlit에서 화면에 공간을 만들어 두었다가 내용이 생길 때 채워 넣는 도구)
