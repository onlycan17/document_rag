# 문서 이중언어(한-영) 관리 정책

## 목적
문서의 한국어/영어 버전을 일관되게 유지하여, 팀 내/외부 이해관계자가 최신 정보를 정확히 접근할 수 있도록 합니다.

## 범위
- 저장소 내 모든 Markdown(`.md`) 문서에 적용합니다.
- 코드 주석 및 README 섹션 내 짧은 문구는 본 정책의 직접 적용 대상이 아닙니다.

## 기본 원칙
- 기본 문서는 한국어를 기준으로 유지합니다.
- 영어 버전이 필요한 경우, 동일 파일명의 영어판을 추가로 관리합니다.

## 파일 명명 규칙
- 한국어 기본 문서: `문서명.md` (예: `INSTALL.md`)
- 영어 문서: `문서명_EN.md` (예: `INSTALL_EN.md`)
- 기타 언어 확장 시: `문서명_<언어코드>.md` (예: `GUIDE_JA.md`)

## 링크 규칙
- 기본적으로 한국어 문서로 링크합니다.
- 필요 시 한국어 문서 상단에 영어판 교차 링크를 제공합니다.
  - 예: `영문 버전: docs/INSTALL_EN.md`

## 변경 프로세스
1. 문서 변경 시, 한국어 본문을 먼저 수정합니다.
2. 의미 변화가 있는 경우, 영어판(`*_EN.md`)도 동시에 반영합니다.
3. PR 설명에 “Docs: KR/EN 동시 반영 여부”를 명시합니다.

## 검증 체크리스트
- 제목/섹션 구조가 KR/EN 간 동일한가?
- 코드 블록, 파일 경로, 명령어는 변경 없이 유지되었는가?
- 내부 링크가 올바른 대상(KR 기본, EN 보조)을 가리키는가?
- 새로 추가된 문서에 영어판이 필요한지 판단하고, 필요 시 즉시 추가했는가?

## 예시
- `docs/INSTALL.md` ↔ `docs/INSTALL_EN.md`
- `AGENTS.md`는 기본 한국어, 필요 시 `AGENTS_EN.md` 추가

## 주기적 점검
- 배포 전 문서 점검 시, KR/EN 동기화 상태를 간단 체크합니다.
- 링크 깨짐(link rot) 점검은 로컬에서 `rg`로 상대경로 참조를 확인합니다.
